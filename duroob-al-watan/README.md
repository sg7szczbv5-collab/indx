# دروب الوطن — العرض التقديمي التفاعلي

عرض تقديمي ويب تفاعلي لمشروع **«دروب الوطن» (Duroob Al-Watan)**: المنصة الوطنية الذكية لتنظيم النقل اللوجستي وإدارة حركة الشاحنات.

**التقنيات:** React 18 + TypeScript + Tailwind CSS + Framer Motion + lucide-react (Vite).

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # فحص TypeScript + بناء نسخة الإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
```

ملفات `dist/` تعمل من أي مسار (`base: './'`)، ويمكن رفعها على أي استضافة ثابتة.

## تعديل المحتوى

كل النصوص والأرقام والأيقونات موجودة في ملف واحد: **`src/data/slidesData.ts`**
(عناوين الشرائح، البطاقات، سعات المواقف، خطوات الرحلة، نسب توزيع المحفظة، الغرامات، مصادر الدخل، العدادات، وبيانات التواصل).

> الأرقام الحالية قيم استرشادية لأغراض العرض. استبدلها بالأرقام المعتمدة قبل العرض الرسمي.

## التنقل

| الإجراء | الاختصار |
| --- | --- |
| الشريحة التالية | `←` أو `Space` أو `PageDown` أو السحب على الشاشة |
| الشريحة السابقة | `→` أو `PageUp` |
| الأولى / الأخيرة | `Home` / `End` |
| الانتقال لشريحة برقمها | `1` … `9`، و`0` للعاشرة |
| ملء الشاشة | `F` |
| قائمة الشرائح | `G` |

رقم الشريحة يظهر في الرابط (`#5`) لمشاركة شريحة محددة مباشرة.

## البنية

```
src/
├── data/slidesData.ts        ← المحتوى كاملاً
├── App.tsx                   ← التنقل، لوحة المفاتيح، الانتقالات
├── components/
│   ├── NavBar.tsx            ← الشريط السفلي (الرقم، العنوان، النقاط، القائمة، ملء الشاشة)
│   ├── SlideLayout.tsx       ← ترويسة موحّدة للشرائح
│   ├── Modal.tsx, Background.tsx, accent.ts
│   └── slides/               ← الشرائح العشر
└── hooks/                    ← useFullscreen, useCountUp
```
