# ألفا ماركت – إعلان كرتوني (Remotion)

فيديو موشن جرافيك كرتوني 2D بمقاس 1080×1920 (9:16) بسرعة 30 إطار/ثانية، ومدته 39 ثانية ليغطي التعليق الصوتي كاملاً (38.5 ثانية).

## التشغيل
```bash
npm install
npm run dev        # Remotion Studio للمعاينة
npm run build      # يُصدِّر out/alfa-market.mp4
npm run typecheck
```

## التعديل
- **`src/constants.ts`**: توقيت المشاهد ومراحل جولة العربة، والنصوص، والألوان، وإعدادات الصوت، و`STORE_INFO` (العنوان، أوقات العمل، الجوال). الحقل الفارغ لا يظهر في الفيديو.
- **`public/voiceover.mp3`**: التعليق الصوتي. عند استبداله عدّل حدود المشاهد في `SCENES`.
- **`src/components/cartoon/`**: كل الرسومات بصيغة SVG مكوّنات React منفصلة:
  `Storefront`, `ShoppingCart`, `Veggies`, `Groceries`, `Breakfast`, `Deals`,
  `NeighborhoodMap`, `Kitchen`, `Character`, `ThoughtBubble`, `Logo`, `Banners`, `Confetti`, `Background`.
- **`src/scenes/`**: المشاهد الخمسة، و`src/Video.tsx` يجمعها مع الانتقالات والصوت.

## المشاهد
| الوقت | المشهد |
|---|---|
| 0 – 7.2 ث | ثلاجة فارغة وفقاعة تفكير فيها قهوة وخبز وحليب: «ناقصك شيء في البيت؟» |
| 7.2 – 17.6 ث | انفجار نجمي يكشف واجهة ألفا ماركت، وينزل الشعار، وتتدلى لافتة «كل اللي تحتاجه في مكان واحد» |
| 17.6 – 28.5 ث | عربة تسوق تتجول في الأقسام: طازج، ثم تنوع، ثم أسعار وعروض |
| 28.5 – 33.5 ث | خريطة الحي وطريق متعرج ودبوس موقع وساعة تغمز: «قريب منك.. وسهل توصل له» |
| 33.5 – 39 ث | الأبواب تُفتح، والشعار، وشريط «حياكم الله، زورونا اليوم!» مع قصاصات ملونة |

الخطوط Lalezar وCairo من حزم `@fontsource` المحلية، فلا يحتاج الرندر إلى إنترنت.
