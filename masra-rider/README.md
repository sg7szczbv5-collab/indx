# مَسْرى — تطبيق الراكب (MASRA Rider)

تطبيق العميل لمنصة مَسْرى، مبني بـ **React Native + Expo + TypeScript**، ويعمل على iPhone وAndroid والمتصفح من نفس الكود.

> نسخة تجريبية: لا يوجد تسجيل دخول حقيقي ولا دفع ولا إرسال رحلات فعلية. كل البيانات من `src/services/api.ts` (خدمة وهمية).

---

## التشغيل في Visual Studio Code

### المتطلبات (مرة واحدة)
1. ثبّت **Node.js 20 أو أحدث** من nodejs.org.
2. ثبّت **Visual Studio Code**.
3. على جوالك ثبّت تطبيق **Expo Go** (من App Store أو Google Play).

### الخطوات
1. في VS Code: `File → Open Folder…` واختر مجلد `masra-rider`.
2. عند ظهور رسالة الإضافات المقترحة اضغط **Install** (Expo Tools وESLint وPrettier).
3. افتح الطرفية: `Terminal → New Terminal` واكتب:
   ```bash
   npm install
   npx expo start
   ```
4. سيظهر **رمز QR** في الطرفية:
   - **iPhone:** افتح الكاميرا وامسح الرمز.
   - **Android:** افتح Expo Go واضغط *Scan QR code*.
5. للتجربة على المتصفح اضغط حرف `w` في الطرفية، أو شغّل `npx expo start --web`.

يمكنك أيضاً التشغيل من قائمة **Run and Debug** (Ctrl+Shift+D) واختيار «تشغيل مَسْرى (Expo)».

> إذا لم يتصل الجوال بالكمبيوتر (شبكتان مختلفتان)، شغّل: `npx expo start --tunnel`

### أوامر مفيدة
| الأمر | الوظيفة |
|---|---|
| `npx expo start` | تشغيل خادم التطوير |
| `npx expo start --web` | التشغيل على المتصفح |
| `npm run typecheck` | فحص أخطاء TypeScript |
| `npx expo-doctor` | فحص توافق الحزم |
| `npx expo install <package>` | إضافة حزمة بإصدار متوافق |

## الشاشات

| المسار | الشاشة |
|---|---|
| `welcome` | الترحيب وإدخال رقم الجوال |
| `otp` | رمز التحقق (أي 4 أرقام في النسخة التجريبية) |
| `(tabs)/index` | الرئيسية: الخدمات، «إلى أين؟»، حولك |
| `(tabs)/activity` | سجل الرحلات |
| `(tabs)/account` | الحساب، المحفظة، وسائل الدفع، تسجيل الخروج |
| `search` | البحث عن الوجهة وإضافة توقف |
| `rides` | اختيار نوع الرحلة والسعر ووسيلة الدفع |
| `pickup` | تأكيد نقطة الالتقاء |
| `searching` | الربط بأقرب سائق |
| `driver` | السائق في الطريق، رمز التحقق، بيانات السيارة واللوحة |
| `trip` | متابعة الرحلة وتفاصيلها وأدوات الأمان |
| `rate` | الأجرة، تقييم السائق، الإكرامية، التعليق |

## هيكل المشروع

```
src/
  app/            ← الشاشات (Expo Router: كل ملف = شاشة)
  components/     ← مكونات مشتركة: النصوص، الأزرار، الخريطة، رسومات السيارات، اللوحة
  data/           ← الأماكن، فئات الرحلات، التسعير التجريبي
  services/api.ts ← الخدمة الوهمية (استبدلها بالـ API الحقيقي)
  store/ride.tsx  ← حالة الرحلة المشتركة بين الشاشات
  hooks/ utils/   ← أدوات مساعدة (التوقيت، الاتجاه من اليمين لليسار)
  theme.ts        ← الألوان والخطوط والهوية
```

## الاتجاه العربي (RTL)
- على الجوال: مفعّل من `app.json` عبر `expo-localization` (`forcesRTL: true`). أول تشغيل في Expo Go قد يحتاج إعادة فتح التطبيق مرة واحدة حتى يُطبَّق الاتجاه.
- على المتصفح: يُضبط `dir="rtl"` تلقائياً، و`src/utils/rtl.ts` يوحّد مواضع العناصر بين الجوال والمتصفح.

## لاستكمال التطبيق الحقيقي
1. **الخادم (Backend):** استبدل الدوال في `src/services/api.ts` باستدعاءات API حقيقية (التحقق بالـ OTP، التسعير، طلب الرحلة، التتبع المباشر عبر WebSocket).
2. **الخرائط:** استبدل `src/components/MapView.tsx` بـ `react-native-maps` أو Mapbox مع مفتاح API، والموقع الحالي عبر `expo-location`.
3. **الدفع:** ربط مزوّد مدفوعات مرخّص في المملكة.
4. **الإشعارات:** `expo-notifications` لتنبيهات وصول السائق.
5. **النشر:** `npx eas-cli build` لإنشاء نسخ App Store وGoogle Play (يتطلب حساب Expo وحسابات المطورين).
6. **المتطلبات النظامية:** الترخيص والربط التقني مع الهيئة العامة للنقل قبل الإطلاق.
